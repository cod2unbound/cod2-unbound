# Windows two-bot replay

All three traces cover 600 ticks of `mp_toujane` in DM, with seed 12345,
50 ms fixed simulation steps and two synthetic clients. The 2026-11-21
Windows scope run used Wine 9.0 and the English Steam game archives.

| File | Source |
| --- | --- |
| `usercmds.txt` | 1,006 synthetic commands generated by `tools/parity/record.py` on scope revision `3eabe367` with `--commands-record --clients 2 --players` |
| `original-statehash.txt.gz` | Replay of that stream on the x64 Unbound Original 1.3 build with the Windows rounding fixes |
| `cod2x-statehash.txt.gz` | Replay of that stream on the x64 Unbound CoD2x 1.4.6.8 build with the Windows rounding fixes |
| `players.txt.gz` | Shared player trace. Both Unbound editions produced identical tracked player fields. |

The updated references change 81 velocity components from `80000000` to
`00000000`, starting at tick 140, client 1, velocity X. In each edition,
78 raw entity hashes change at ticks with a velocity sign change. All
quantized hashes and all other tracked player fields match the prior traces.

The edition-specific state traces preserve the expected raw entity hash
difference. Line endings are normalized to LF. The fixture contains synthetic
input and numeric simulation records. Supply licensed map data locally to
run it.
