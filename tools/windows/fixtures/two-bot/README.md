# Windows two-bot replay

The traces cover 600 ticks of `mp_toujane` in DM, with seed 12345,
50 ms fixed simulation steps and two synthetic clients. The 2026-11-21
Windows scope run used Wine 9.0 and the English Steam game archives.

| File | Source |
| --- | --- |
| `usercmds.txt` | 1,004 synthetic commands, plus a header and an end record, generated by `tools/parity/record.py` on scope revision `3eabe367` with `--commands-record --clients 2 --players` |
| `original-statehash.txt.gz`, `original-players.txt.gz` | x64 Unbound Original 1.3 replay with the Windows rounding and spectator movement fixes |
| `cod2x-statehash.txt.gz`, `cod2x-players.txt.gz` | x64 Unbound CoD2x 1.4.6.8 replay with the Windows rounding fixes |

The Windows velocity snapping fix changed 81 zero signs in each edition.
The Windows Original 1.3 spectator movement calculation now follows the
retail arithmetic order, so the editions have separate player traces.

The edition-specific state traces preserve the expected raw entity hash
difference. Line endings are normalized to LF. The fixture contains synthetic
input and numeric simulation records. Supply licensed map data locally to
run it.
